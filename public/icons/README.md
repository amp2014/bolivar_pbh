# App Icons

Place these files here before deploying:
- `icon-192.png` — 192×192 PNG for Android home screen
- `icon-512.png` — 512×512 PNG for splash screen / high-res
- `apple-touch-icon.png` — 180×180 PNG for iOS Add to Home Screen

Tip: Generate all sizes from a single 1024×1024 source using
https://maskable.app or https://realfavicongenerator.net
